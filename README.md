# 소개

## 개발 동기

&nbsp;&nbsp;&nbsp;&nbsp;누구나 **자신이 원하는** 인공지능 버츄얼 유튜버를 만들고, 실제 방송까지 하는 것을 도와주고자 이 프로젝트를 시작하였습니다.

## 목표

&nbsp;&nbsp;&nbsp;&nbsp;**나만의 인공지능**을 만들고, **직접 방송**하며 **가상 버츄얼 유튜버**의 기본이 될 수 있게 도와줍니다.
